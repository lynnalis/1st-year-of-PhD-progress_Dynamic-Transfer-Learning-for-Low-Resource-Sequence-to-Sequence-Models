This repository documents the progress and implementations from my first year of PhD research. 
It focuses on exploring the kNN-TL (k-Nearest-Neighbor Transfer Learning) paper and framework, adapting its inference mechanisms specifically for low-resource settings.
The core objective of this work is to tweak and optimize the framework to effectively serve the Moroccan Arabic dialect (Darija) (PADIC & MADAR datasets) in Neural Machine Translation tasks.
